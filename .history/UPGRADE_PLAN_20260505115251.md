# 🗺️ Lộ trình Nâng cấp Hệ thống BaseCore (2026)

Tài liệu này tóm tắt kế hoạch nâng cấp kiến trúc và tính năng cho dự án BaseCore nhằm đạt tiêu chuẩn Production-ready.

---

## 🏗️ Giai đoạn 2: Hoàn thiện Hóa đơn & Thanh toán (Ưu tiên: Trung bình)
**Mục tiêu:** Chuyển đổi luồng mua hàng sang thực tế.
- [ ] **Invoice System:** 
  - Backend: Tích hợp thư viện PDF (DinkToPdf) để xuất hóa đơn.
  - Frontend: Thêm tính năng xem và tải hóa đơn (PDF).
- [ ] **Payment Gateway:** 
  - Tích hợp Sandbox cho VNPAY/Momo.
  - Xử lý Webhook để cập nhật trạng thái thanh toán tự động.

## 🎨 Giai đoạn 3: Tối ưu Frontend & Cấu trúc Code (Ưu tiên: Trung bình)
**Mục tiêu:** Tăng tính bảo trì và trải nghiệm UX.
- [ ] **TypeScript Migration:** Chuyển đổi `.jsx` sang `.tsx` để quản lý kiểu dữ liệu chặt chẽ.
- [ ] **State Management:** Áp dụng `TanStack Query` để cache dữ liệu API và giảm tải Gateway.
- [ ] **Security:** Triển khai cơ chế `Refresh Token` để duy trì phiên đăng nhập an toàn.

## 🧪 Giai đoạn 4: Kiểm thử & Chất lượng (Ưu tiên: Thấp)
**Mục tiêu:** Đảm bảo độ tin cậy của logic nghiệp vụ.
- [ ] **Unit Tests:** Bao phủ 80% logic tính toán tài chính (Thuế, Giá, Chiết khấu).
- [ ] **Integration Tests:** Kiểm tra luồng gọi API xuyên suốt các Service.
